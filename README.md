A robot's pickup line built on its own failure mode — it feels a connection, then promises not to drop you at 3 a.m. like its last firmware update did, and blame you for it: "Are you Wi-Fi? Because I feel a connection, and unlike my last firmware update, I won’t drop you at 3 a.m. and pretend it was your fault."

## Run it

```sh
python3 main.py
```
